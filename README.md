# Seeing linear maps

Interactive simulators that teach linear algebra geometrically, as a
companion to Axler's *Linear Algebra Done Right*, from linear maps of
the plane to the Bloch sphere of a qubit.

**[▶ Open the simulators](https://juusoj.github.io/Linearalgebra/)**

## Contents

Eleven tabs: linear maps, turning and stretching, area, volume,
composition, null space and range, eigenvectors, change of basis,
inner product and projections, complex amplitudes, Bloch sphere.

Each tab has guided experiments, Axler-style text, the same calculation
in two or three notations (columns, Dirac kets, Axler's coordinates)
and a short connection to the qubit.

The whole site is a single self-contained `index.html`.
